# Style Preset 参考

本文件只负责两件事：帮助 Plan 阶段选择一个 `Style Preset`，以及提供素材生成所需的视觉气质上下文。Plan 阶段默认只读本文件，不读取具体 preset reference。

Preset 只定义基础风格方向、默认色彩锚点、图表 palette 和适合使用的素材 cue。素材 cue 是适合使用的素材线索，不代表系统已经生成或自动支持这些素材；强主题、品牌主题或活动舞台主题仍需在 `Story Visual Identity`、`Asset Registry` 和必要的 `Style Overrides` 中具体化。

不要把本文件当成 CSS/token 源。默认不要向 `plan.md` 复制 CSS 变量、hex 色值、字体栈、DOM class、图表主题代码或输出格式映射。构建/运行时会根据 preset 名称解析具体页面样式与图表主题。

## Preset 选择矩阵

| Preset | 适合 / 气质 | 场域与色彩锚点 | 素材 cue | 谨慎点 |
|---|---|---|---|---|
| **Swiss Modern** | 商业、金融、经营汇报、精确对比；克制、分析型、系统化 | 白底或浅灰 surface；克制红色强调；图表色板干净、对比明确 | 几何线条、网格节奏、稀疏模块化标记、受控强调点 | 品牌主色明显不匹配时，再按 `SKILL.md` 判断是否覆盖；避免装饰堆叠、商务图库隐喻、伪仪表盘 |
| **Indigo Porcelain** | 研究、工程、技术分析、证据密集报告；冷静、严谨、技术可信 | 冷白研究纸面；靛蓝与青瓷绿强调；图表偏蓝绿技术色板 | 技术示意线、精密注释轨迹、论文式细规则线、冷色标记 | 需要更暖、更消费或更运动时优先换 preset，不要硬改；避免亮面 SaaS 渐变、全蓝单调、通用电路板意象 |
| **Dark Botanical** | 高级编辑视觉、可持续、地球系统、克制风险叙事；沉稳、自然、电影感 | 深蓝黑 / 矿物暗场；暖金橙与低亮度金绿强调 | 有机线条、层理或颗粒质感、自然系统感抽象纹理；具象植物 / 地貌只在主题相关时使用 | 适合深色但带自然系统感的故事；若是城市事件、体育或游戏，不要只因为想要深色就选它；避免恐怖氛围、丛林写实、浑浊低对比 |
| **Pudding Neon** | 发布、趋势、增长、高能量公共解释；大胆、流行、高对比、现代 | 深灰暗场；霓虹黄为默认强调；图表含黄、珊瑚、青、紫等高能对比 | 霓虹轮廓、发光抽象形、数据感能量轨迹、节奏化色块 | 适合高能表达，但不要把默认霓虹 cue 当成完整主题实现；避免赛博朋克套话、过度发光、噪声拼贴 |
| **Warm Earth** | 消费、生活方式、社区、健康、人与行为；亲和、温暖、有触感 | 温暖浅底；陶土粉橙强调；图表偏柔和暖色 | 柔软有机形、轻材料感、温暖标记、手绘感简单几何；生活 / 社区物件只在主题相关时使用 | 品牌或题材偏冷、科技、严肃调查时优先换 preset；避免米色单调、乡村杂乱、煽情图库感 |
| **Vintage Editorial** | 媒体解释、文化议题、有态度的编辑故事；机智、杂志感、有辨识度 | 暖纸底；深玫红强调；图表带编辑式强调色 | 编辑版面碎片、档案感形状、剪纸节奏、克制强调色块；报刊 / 档案元素只在主题相关时使用 | 需要复古编辑感但主色明显不匹配时，再按 `SKILL.md` 判断是否覆盖；避免假报纸正文、复古猎奇、密集海报拼贴 |
| **Paper & Ink** | 调查、政策、治理、严肃公共议题；文学感、证据优先 | 纸张浅底；克制红色强调；图表偏蓝灰、墨色、调查感 | 墨线、蓝灰编辑标记、纸张纹理、克制证据注释、文档边界感 | 严肃故事一般不要强主题化覆盖；避免装饰花纹、难读手写标签、重插画、伪造可读文本 |

## 选择规则

1. 按故事的证据姿态、受众和发布场景选择，不按“喜欢哪个颜色”选择。
2. 受众需要快速理解、低视觉风险、偏业务汇报时，默认优先 **Swiss Modern**。
3. 可信度依赖来源、方法、调查或证据链时，优先 **Paper & Ink** 或 **Indigo Porcelain**。
4. 增长、发布、城市事件、体育、游戏、娱乐或强主题专题，可以优先评估 **Pudding Neon**；高密度内部汇报不要默认用它。
5. 温度、社区、消费或文化态度支撑核心论点时，再选 **Warm Earth** 或 **Vintage Editorial**。
6. **Dark Botanical** 必须有自然系统、可持续、地球系统或克制风险叙事理由；不要把它当普通深色主题。
7. 整篇故事只能选择一个 preset。章节可以变化构图，但不能发明新的视觉世界。
8. 选定 preset 后，不要因为矩阵里的素材 cue 看起来匹配就默认主题已经完成。如果用户明确要求品牌色、领域色、强主题舞台氛围，或 `feature` 主题需要比 preset 默认更强的场景识别，回到 `SKILL.md` 判断是否需要 `Style Overrides`；具体写法只读 [style-overrides.md](style-overrides.md)。

## 写入 plan.md

写 `plan.md` 时：

- `Style Preset` 只能填写本文件中的一个 preset 名称。
- 把所选 preset 的气质、场域、色彩锚点和素材 cue 写入 `Story Visual Identity`。
- `Story Visual Identity` 应同时包含故事主题、视觉语言、反复出现的 motif 和避免方向。
- 每个待生成素材的 `visual_brief` 必须结合 preset 上下文、故事领域和该素材的叙事目的。
- 不要请求随机装饰。素材必须强化故事视觉身份、章节意图或记忆点。

示例视觉简报形态：

```markdown
visual_brief: "Paper & Ink 语境：纸张浅底、克制红色强调、蓝灰墨线证据注释；用抽象政策文件边界和精确线性标记支撑本章证据链；避免装饰花纹、假文字和重插画。"
```
