# 图表文件校验与交付

创建、修改或修复图表文件时执行。只讨论或解释、未修改文件时，可以直接回答。

1. **保存源码**：基于当前源文件修改，保留仍有效的数据与需求；保存完整 `spec.js`，包括配置依赖的辅助函数。
2. **执行校验**：标准演示使用 `python3 "<SKILL_DIR>/scripts/generate_demo_html.py" --spec-file "<实际源文件>" --output-dir "<当前输出目录>"`，生成器会先校验配置。其他展示方式先对图表的纯 JS 配置执行 `node "<SKILL_DIR>/scripts/validate_spec.cjs" "<实际源文件>"`。修正错误后重跑，校验后修改源码也需重跑。
3. **核对 HTML**：生成与本轮源码对应的可运行 HTML，确认文件存在，路径以生成器实际输出为准。静态校验（包括 `RUNTIME_VALIDATION_DEFERRED`）不证明渲染正确；有浏览器能力时检查数据图形、标签和所需交互，否则说明尚未验证显示效果。
4. **交付文件**：返回本轮源码和 HTML 的真实路径或文件链接，不能只回复“已修复”或指向旧版本。回复格式遵循当前宿主明确提供的协议；未指定时直接提供文件链接，并说明改动及验证范围。生成失败时如实报告，不声称已交付。
